# Prior-Art Threats

The contribution is **not** “information-aware resource allocation.” That space
already contains Value of Information (VoI), Quality of Information (QoI),
energy-aware QoI maximization, energy-harvesting VoI control, task-oriented
semantic communication, and cross-layer semantic resource allocation.

Representative threats to novelty:

- Alawad & Kraemer, *Value of Information in Wireless Sensor Network
  Applications and the IoT*, IEEE Sensors Journal, 2022, DOI
  10.1109/JSEN.2022.3165946.
- Du & Yang, *Energy-aware quality of information maximisation for wireless
  sensor networks*, IET Communications, 2016, DOI 10.1049/iet-com.2015.1064.
- Patil & Fiems, *The value of information in energy harvesting sensor
  networks*, Operations Research Letters, 2018, DOI 10.1016/j.orl.2018.04.002.
- Liu et al., *Bandwidth and Power Allocation for Task-Oriented Semantic
  Communication*, 2022, arXiv:2201.10795.
- Chen et al., *Task-Oriented Resource Allocation for Cross-Modal Semantic
  Communications*, IEEE Network, 2025, DOI 10.1109/MNET.2025.3628505.
- Recent semantic/MEC work continues to jointly allocate compute and
  communication resources using task utility.

Therefore this artifact makes a narrower claim: **a tiny, deterministic,
application-agnostic utility contract at the worker boundary of an
ultra-low-power embedded OS**, with explicit bounded overhead, legacy fallback,
dynamic hints, and a hardware validation protocol.

A publication must perform a fresh systematic search before making a novelty
claim.
